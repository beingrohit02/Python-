Python Learning & Notes Repository
Overview
A structured personal repository dedicated to documenting my journey learning Python programming fundamentals, data structures, and practical application development. This repository serves as a centralized knowledge base, code snippet library, and portfolio for mini-projects as part of my B.Tech CSE (AI & ML) coursework.

Repository Structure
01-Fundamentals/ – Core programming concepts including conditional statements, while and for loops, operators, and basic syntax.

02-Data-Structures/ – Hands-on implementations and notes on lists, dictionaries, tuples, and sets.

03-Functions-Modules/ – Reusable code blocks, scope, modular programming, and custom utility scripts.

04-Projects/ – Standalone mini-projects and practical applications combining Python with hardware (such as my custom Arduino game controller project).

Technologies & Tools
Language: Python 3.x

Hardware & Protocols: Arduino, Serial Communication (PySerial)

Environment: Git & GitHub for version control
